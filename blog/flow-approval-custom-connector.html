Custom Connector for Power Automate Approvals

Introduction

Approvals are a key part of business processes built on the Power Platform. While you can use HTTP with Azure AD or other direct approaches, a Custom Connector gives you a reusable, secure, and user-friendly way to interact with approvals in both Power Automate and Power Apps.

In this guide (and in the video below), I’ll walk you through how to:

  • Create a Custom Connector for Approvals using Swagger.
  • Register an Entra ID (Azure AD) App for secure authentication.
  • Test the connector with a real approval flow.
  • Use the connector directly in Power Apps.

By the end, you’ll have a connector that supports three key actions:

  • Get Approval Details (with available response options).
  • Reassign Approval.
  • Complete Approval.

⚠️ Disclaimer: The connector in this guide uses api.flow.microsoft.com. You can use it at your own risk. This is not an official Microsoft-supported web service.

Creating the Custom Connector

Or you can download the file from here: Flow-Approval-API.swagger.json

Once downloaded/copied, go to the Power Platform admin center → Data → Custom Connectors → New Custom Connector and choose Import from OpenAPI file. Upload the Swagger file and you’ll see the three operations ready to use:

  • Get Approval Details → returns details including available response options.
  • Reassign Approval → reassigns the approval to another user.
  • Complete Approval → completes the approval with Approve or Reject.

The benefit of packaging this as a connector instead of making raw HTTP calls is that it becomes reusable, secure, and much easier for app makers to work with.

Entra ID App Registration & Permissions

The connector requires secure authentication against Microsoft Entra ID (Azure AD).

  1. Go to Entra admin portal → App registrations → New registration.

  2. Note down the Client ID and Tenant ID after creation.

  3. Create a Client Secret.

  4. Under API Permissions, add:

    • Approvals.Read.All
    • Approvals.Manage.All

  5. In your Custom Connector’s Security tab, configure OAuth 2.0 with these values:

  • Identity Provider: Azure Active Directory

  • Client ID: App Registration Client ID

  • Client Secret: Generated client secret

  • Authorization URL: https://login.microsoftonline.com

  • Tenant ID: common

  • Resource URL: https://service.flow.microsoft.com

  1. After saving the connector, do not forget to add the Redirect URL (shown in the connector’s security tab) into your App Registration in Entra. This step is required for the authentication flow to succeed.

This ensures that only authenticated and authorized apps can interact with the Approvals APIs.

Summary

With this setup, you now have a reusable connector that works across apps and flows. Use cases include:

  • Completing approvals directly from a Power App without opening Power Automate.
  • Reassigning approvals to another user.
  • Displaying approval details and available response options in a custom UI.
  • Debugging approval flows by calling the connector from the Test tab.

This approach simplifies working with approvals, saves time for app makers, and keeps authentication secure.

✅ Try it yourself: Download the Swagger file, set up the Entra app, and plug it into your apps. Once configured, you’ll have full control of Approvals directly in Power Apps.
