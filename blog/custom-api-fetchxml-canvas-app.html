Custom API: Run Complex FetchXML Queries from Canvas App

Have you ever needed to run a complex query across multiple tables in Dataverse and thought you had no choice but to build a Power Automate Flow? Flows work, but they add extra latency and maintenance overhead.

In this tutorial, I’ll show you how to call complex FetchXML queries directly from a Canvas App using a POST Custom API, without using a Flow. You’ll learn how to:

  • Build a signed C# plugin DLL
  • Register a POST Custom API in Dataverse
  • Call the API from a Canvas App
  • Parse the returned JSON into a typed collection for use in a Table control

Here’s the video walkthrough:

Step 1: Preparing the Environment

  1. Open Visual Studio and create a new Class Library (.NET Framework) project targeting .NET Framework 4.6.2 or newer.
  2. Add the following NuGet packages:
    • Microsoft.CrmSdk.CoreAssemblies
    • Microsoft.CrmSdk.XrmTooling.CoreAssembly
  3. Sign the DLL:
    Right-click the project → Properties → Signing → check Sign the assembly, create a new key file (e.g., HackThePlatformKey.snk). Dataverse requires signed assemblies for plugins.

Step 2: Writing the Plugin

The plugin takes a FetchXML string, executes it, and returns JSON:

using Microsoft.Xrm.Sdk;
using Microsoft.Xrm.Sdk.Query;
using Newtonsoft.Json;
using System;
using System.Collections.Generic;

namespace HackThePlatform.Plugins
{
    public class FetchXmlToJsonPlugin : IPlugin
    {
        public void Execute(IServiceProvider serviceProvider)
        {
            var context = (IPluginExecutionContext)serviceProvider.GetService(typeof(IPluginExecutionContext));
            var serviceFactory = (IOrganizationServiceFactory)serviceProvider.GetService(typeof(IOrganizationServiceFactory));
            var service = serviceFactory.CreateOrganizationService(context.UserId);

            if (!context.InputParameters.Contains("fetchxml") || !(context.InputParameters["fetchxml"] is string))
                throw new InvalidPluginExecutionException("FetchXML input parameter is missing or invalid.");

            string fetchXml = (string)context.InputParameters["fetchxml"];
            var result = service.RetrieveMultiple(new FetchExpression(fetchXml));

            var list = new List<Dictionary<string, object>>();
            foreach (var entity in result.Entities)
            {
                var dict = new Dictionary<string, object>();
                foreach (var attr in entity.Attributes)
                {
                    dict[attr.Key] = attr.Value;
                }
                list.Add(dict);
            }

            string json = JsonConvert.SerializeObject(list, Formatting.None);
            context.OutputParameters["json"] = json;
        }
    }
}

Step 3: Registering the POST Custom API

  1. Open the Plugin Registration Tool and register your signed assembly.
  2. Create a Custom API with the following configuration:
SettingValue
Name`crad2_FetchXmlToJsonPlugin`
Display Name`FetchXML to JSON Plugin`
Bound EntityNone
Is Function**No** (POST request)
Plugin Type`HackThePlatform.Plugins.FetchXmlToJsonPlugin`
Input Parameter`fetchxml` (String)
Output Parameter`json` (String)

Using a POST API allows you to send large or complex FetchXML queries from Canvas Apps without relying on Flows.

Step 4: Calling the API from Canvas App

  1. Add your Environment connector in Power Apps.
  2. Add a button and set its OnSelect formula:
Set(
    result,
    Environment.crad2_FetchXmlToJson({fetchxml: "
        <fetch top='10' aggregate='true'>
            <entity name='contact'>
                <attribute name='parentcustomerid' groupby='true' alias='accountid'/>
                <attribute name='contactid' aggregate='count' alias='contactcount'/>
                <link-entity name='account' from='accountid' to='parentcustomerid' alias='acc'>
                    <attribute name='name' groupby='true' alias='accountname'/>
                </link-entity>
                <order alias='contactcount' descending='true'/>
            </entity>
        </fetch>"
    })
);
  1. Parse the JSON into a collection:
Set(
    array,
    ForAll(
        ParseJSON(result.json),
        {
            contacts: ThisRecord.contactcount.Value,
            accountname: ThisRecord.accountname.Value
        }
    )
);
  1. Bind the collection to a Table control

    The Table now displays the top 10 accounts with the most contacts dynamically.

Step 5: Testing

Click the button in your Canvas App and verify that the Table populates correctly with aggregated contact counts. This approach is:

  • Secure: DLL is signed
  • Flexible: POST API handles complex queries
  • Efficient: No Flow required
  • Powerful: FetchXML across multiple tables directly from Canvas Apps

Summary

In this tutorial, we:

  1. Created a signed plugin DLL in Visual Studio.
  2. Registered a POST Custom API in Dataverse.
  3. Ran a complex FetchXML query to aggregate contacts per account.
  4. Parsed the JSON response in a Canvas App and displayed it in a Table.

This method is cool because it:

  • Eliminates the need for a Flow
  • Handles large or complex queries efficiently
  • Keeps your Canvas App dynamic and responsive
  • Uses secure, maintainable, and reusable code
