Auto-Generate Azure Blob Folders from Dataverse Using a Plugin

Hey everyone 👋 welcome back to Hack the Platform, where we explore practical ways to extend and “hack” Microsoft’s ecosystem.

In this post, we’ll build a Dataverse plugin that automatically creates a folder in Azure Blob Storage whenever a new record is created. We'll do this using generic HTTP REST calls, without relying on the Azure.Storage.Blobs library.

Why This Plugin?

Imagine you have a Dataverse table where each record needs a dedicated folder in Azure Blob Storage. Manually creating these folders and updating records is tedious. With this plugin, the process becomes fully automated:

  1. User creates a record in Dataverse.
  2. Plugin triggers on creation.
  3. Plugin calls Azure Blob Storage REST API to create a folder.
  4. Plugin updates the record with the folder URL.

You could do this with Power Automate, but a synchronous Dataverse plugin is superior because it is:

  • Immediate: Executes inside the create transaction (no delay).
  • Atomic: Failure rolls back the record (no orphan rows).
  • Deterministic: Record Id available directly.
  • Fast: No connector serialization or throttling overhead.
  • Secure: SAS token stays in server-side secure configuration.
  • Clear on errors: Tracing + exceptions surface issues instantly.
  • Low maintenance noise: No flow runs/history clutter or metered actions.
  • Maintainable: Versioned, compiled C# under source control.
  • Lightweight: Single HttpClient REST call; minimal dependencies.

Result: faster, safer, cleaner, and more predictable than a flow.

Prerequisites

Before we start coding, make sure you have:

  • Visual Studio installed (we'll use .NET Framework 4.6.2)
  • Power Platform CLI (pac CLI) for plugin registration
  • Dataverse table with 2 columns:
    • Name (text)
    • FolderUrl (text)
  • An Azure Storage account, a container, and a SAS token for authentication
  • A strong name key to sign the plugin assembly

Step 1: Set Up Azure Blob Storage

  1. Go to your Azure Storage account.
  2. Create a container (e.g., dataverse-folders).
  3. Generate a SAS token with write permissions.

We'll use this SAS token in the plugin’s secure configuration.

Step 2: Create a Dataverse Table

For this example, create a table called crc39_example with:

  • Name (Text)
  • FolderUrl (Text)

Optionally, generate a Model-Driven App to test the plugin after creation.

Step 3: Create the Plugin Project in Visual Studio

  1. Open Visual Studio → New Project → Class Library (.NET Framework 4.6.2).
  2. Add the following NuGet packages:
    • Microsoft.CrmSdk.CoreAssemblies
    • Microsoft.CrmSdk.XrmTooling.CoreAssembly
  3. Sign the assembly with a strong name key.

Step 4: Plugin Code

Here’s the plugin we’ll use. Note the unsecure configuration holds the storage account + container, and secure configuration holds the SAS token:

using Microsoft.Xrm.Sdk;
using Microsoft.Xrm.Sdk.Query;
using System;
using System.Net.Http;
using System.Text;

namespace HackThePlatform.Plugins
{
public class CreateBlobFolderRestPlugin : IPlugin
{
private readonly string \_unsecureConfig;
private readonly string \_secureConfig;

        public CreateBlobFolderRestPlugin(string unsecureConfig, string secureConfig)
        {
            _unsecureConfig = unsecureConfig;
            _secureConfig = secureConfig;
        }

        public void Execute(IServiceProvider serviceProvider)
        {
            var context = (IPluginExecutionContext)serviceProvider.GetService(typeof(IPluginExecutionContext));
            var tracing = (ITracingService)serviceProvider.GetService(typeof(ITracingService));
            var factory = (IOrganizationServiceFactory)serviceProvider.GetService(typeof(IOrganizationServiceFactory));
            var service = factory.CreateOrganizationService(context.UserId);

            try
            {
                if (!context.MessageName.Equals("Create", StringComparison.OrdinalIgnoreCase))
                    return;

                if (!context.OutputParameters.Contains("id"))
                    throw new InvalidPluginExecutionException("No record ID found in context.");

                Guid recordId = (Guid)context.OutputParameters["id"];
                tracing.Trace($"Record ID: {recordId}");

                string storageAccount = null;
                string containerName = null;

                if (!string.IsNullOrWhiteSpace(_unsecureConfig))
                {
                    var parts = _unsecureConfig.Split(new[] { ';' }, StringSplitOptions.RemoveEmptyEntries);
                    foreach (var p in parts)
                    {
                        int idx = p.IndexOf('=');
                        if (idx <= -1) continue;
                        var key = p.Substring(0, idx).Trim();
                        var val = p.Substring(idx + 1).Trim();

                        if (key.Equals("Account", StringComparison.OrdinalIgnoreCase) ||
                            key.Equals("StorageAccount", StringComparison.OrdinalIgnoreCase))
                            storageAccount = val;
                        else if (key.Equals("Container", StringComparison.OrdinalIgnoreCase))
                            containerName = val;
                    }
                }

                if (string.IsNullOrWhiteSpace(storageAccount))
                    throw new InvalidPluginExecutionException("Storage account name missing in unsecure configuration.");
                if (string.IsNullOrWhiteSpace(containerName))
                    throw new InvalidPluginExecutionException("Container name missing in unsecure configuration.");

                string sasToken = _secureConfig?.TrimStart('?');
                if (string.IsNullOrWhiteSpace(sasToken))
                    throw new InvalidPluginExecutionException("Secure configuration (SAS token) missing.");

                string folderName = recordId.ToString();
                string blobName = $"{folderName}/.keep";

                string blobUrl = $"https://{storageAccount}.blob.core.windows.net/{containerName}/{blobName}?{sasToken}";
                tracing.Trace($"Creating blob at URL: {blobUrl}");

                using (var http = new HttpClient())
                {
                    http.DefaultRequestHeaders.Add("x-ms-blob-type", "BlockBlob");
                    http.DefaultRequestHeaders.Add("x-ms-version", "2023-11-03");

                    var response = http.PutAsync(blobUrl, new StringContent(string.Empty, Encoding.UTF8, "text/plain")).Result;
                    if (!response.IsSuccessStatusCode)
                    {
                        string msg = $"Azure Blob creation failed: {(int)response.StatusCode} {response.ReasonPhrase}";
                        tracing.Trace(msg);
                        throw new InvalidPluginExecutionException(msg);
                    }
                }

                string folderUrl = $"https://{storageAccount}.blob.core.windows.net/{containerName}/{folderName}/";
                var update = new Entity(context.PrimaryEntityName, recordId)
                {
                    ["crc39_folderurl"] = folderUrl
                };

                service.Update(update);
                tracing.Trace($"Folder created and FolderUrl updated to: {folderUrl}");
            }
            catch (Exception ex)
            {
                tracing.Trace("Exception in CreateBlobFolderRestPlugin: " + ex);
                throw new InvalidPluginExecutionException("Error in plugin: " + ex.Message, ex);
            }
        }
    }

}

Step 5: Build and Register the Plugin Manually with PAC PRT

  1. Build the project in Visual Studio to generate your .dll.

  2. Open the Power Platform CLI Plugin Registration Tool (PRT):

    • Run pac plugin in your terminal or use the PRT GUI.
    • Connect to your Dataverse environment.

  3. Add a new Plugin Assembly:

    • Choose Register New → Plugin Assembly.
    • Browse and select your .dll.
    • Provide a name, description, and version.
    • Ensure the assembly is signed with your strong name key.

  4. Register Plugin Step:

    • Click Register New Step.
    • Select the Dataverse table you created.
    • Set the Message to Create.
    • Choose Execution Mode: Synchronous (recommended).
    • Add Unsecure Configuration:
      Account=yourstorage;Container=dataverse-folders
    • Add Secure Configuration:
      ?yourSASToken

  5. Save and publish the plugin.

  6. Verify the plugin step is enabled and correctly associated with the Create message.

Step 6: Test the Plugin

  1. Open your Model-Driven App.
  2. Create a new record in your Dataverse table.
  3. Check that the folder appears in Azure Blob Storage.
  4. Verify that the FolderUrl field in Dataverse is updated with the new folder path.

Summary

With this plugin, every new record in Dataverse automatically gets its Azure Blob Storage folder. Using REST calls keeps it lightweight and avoids extra dependencies.
